# CI con matriz por microservicio

Usa el script uild-and-test.ps1 (Windows) o crea uno equivalente para compilar y testear cada microservicio con su .sln de forma independiente por matriz.

Microservicios y soluciones:
- ms-auth: ms-auth.sln
- ms-inventory: MsInventory.sln
- ms-iot-monitoring: Iot.sln
- ms-irrigation: Irrigation.sln
- ms-delivery: MsDelivery.sln
- ms-services: MsServices.sln
